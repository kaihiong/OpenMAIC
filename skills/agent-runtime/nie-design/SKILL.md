# NIE design

This skill sets the **look** of every interactive page in the course. It does not
change the course plan: keep whatever structure the teacher asked for or another
active skill prescribes (scene count, scene types, widget types).

While this skill is in use, each interactive page is generated with the NIE design
system: NIE blue, red and yellow, a white title band with an NIE blue, red and yellow stripe,
white cards on a cool grey page, pill buttons and clean sliders, Material Symbols icons,
and theme tokens so the page follows the learner's light or dark setting. Pages are
laid out as one 1280×720 screen with no page scroll.

Slides and quizzes keep OpenMAIC's standard look.

When you plan interactive pages, nothing extra is needed from you; the design is
applied when each page is generated. If the teacher asks why the pages look the
way they do, say the NIE design skill is active.
